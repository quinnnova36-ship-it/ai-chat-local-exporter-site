AI Chat Local Exporter — 隐私政策

最后更新：2026 年 8 月 12 日

一句话概括

本扩展会处理你当前打开的 AI 对话，但插件作者不会收到、保存、出售或查看这些内容。导出整理和文件生成在你的浏览器里完成，文件直接保存到你的电脑。

ChatGPT 快速导出和 DeepSeek 完整历史导出会向对应平台自己的服务器请求当前会话。请求使用你当前的登录状态，数据不会发送到插件作者的服务器；本扩展没有开发者数据服务器。

本扩展会处理哪些数据

  • 你当前打开的 AI 对话内容，包括用户提问、AI 回答和可识别的附件名称或类型。
  • 当前会话的网址、标题和平台信息，用于识别会话并生成本地文件名。
  • ChatGPT 和 DeepSeek 当前登录会话提供的临时凭据，仅用于向对应平台请求当前会话。

插件作者不会收到这些数据。扩展不建立用户账号，不保存对话数据库，不投放广告，也不使用统计或崩溃上报服务。

本扩展如何工作

  1. 你在受支持的 AI 对话页面上主动点击导出。
  2. 扩展从当前页面读取对话；使用 ChatGPT 快速导出或 DeepSeek 完整历史导出时，还会向对应平台自己的服务器请求当前会话。
  3. 扩展在你的浏览器内把对话整理为 Markdown、Text、CSV 或 JSON。
  4. 浏览器把文件保存到你选择的本地位置。

关于网络请求

大多数受支持的平台由扩展读取当前页面中的对话内容。以下两种导出会额外向平台自己的服务器请求当前会话：

  • ChatGPT 快速导出：扩展向 ChatGPT 自己的登录会话接口和当前会话接口发出请求，只读取你当前打开的会话和当前回答分支。
  • DeepSeek 完整历史导出：扩展向 DeepSeek 自己的历史接口请求你当前打开的会话。

这些请求都从你的浏览器发往对应 AI 平台自己的服务器，并使用 HTTPS。登录凭据只在完成本次请求时临时使用，不写入扩展存储，不进入导出文件或诊断信息，也不会发送给插件作者。

数据用途与保留

  • 对话内容和登录凭据只用于完成你主动发起的当前会话导出。
  • 扩展不会把这些数据用于广告、用户画像、信用判断或与导出无关的用途。
  • 扩展不会把对话内容或登录凭据保存在开发者服务器；本地导出文件由你自行管理和删除。
  • 本扩展对用户数据的使用遵守 Chrome Web Store 用户数据政策，包括 Limited Use 要求。

AI Chat Local Exporter — Privacy Policy

Last updated: August 12, 2026

Summary

This extension processes the AI conversation you currently have open, but the developer does not receive, store, sell, or view that content. Formatting and file generation happen in your browser, and the exported file is saved directly to your computer.

ChatGPT fast export and DeepSeek complete-history export request the current conversation from the corresponding platform's own servers using your current signed-in session. The data is not sent to the extension developer, and the extension has no developer-operated data server.

Data Processed by the Extension

  • The AI conversation currently open, including user prompts, AI responses, and recognizable attachment names or types.
  • The current conversation URL, title, and platform information, used to identify the conversation and create a local file name.
  • Temporary authentication credentials supplied by the current ChatGPT or DeepSeek session, used only to request the current conversation from that platform.

The developer does not receive this data. The extension creates no user account, stores no conversation database, serves no ads, and uses no analytics or crash-reporting service.

How It Works

  1. You actively start an export on a supported AI conversation page.
  2. The extension reads the conversation from the current page. ChatGPT fast export and DeepSeek complete-history export also request the current conversation from the corresponding platform's own servers.
  3. The extension formats the conversation as Markdown, Text, CSV, or JSON in your browser.
  4. Your browser saves the file to a local location you choose.

Network Requests

Most supported platforms are exported from conversation content available in the current page. Two export paths also request the current conversation from the platform's own servers:

  • ChatGPT fast export: requests the current signed-in session and the conversation currently open in ChatGPT, following only the selected answer branch.
  • DeepSeek complete-history export: requests the conversation currently open from DeepSeek's own history endpoint.

Both requests travel over HTTPS from your browser to the corresponding AI platform. Authentication credentials are used only in memory for the current request. They are not written to extension storage, included in exports or diagnostics, or sent to the extension developer.

Data Use and Retention

  • Conversation content and authentication credentials are used only to complete the current conversation export you requested.
  • The extension does not use this data for advertising, user profiling, credit decisions, or any purpose unrelated to exporting the conversation.
  • No conversation content or authentication credentials are retained on a developer server. You control and delete the local exported files.
  • This extension's use of user data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Supported Sites

ChatGPT, Google Gemini, Claude, Grok, DeepSeek, Doubao, Kimi, Tencent Yuanbao, Tongyi Qianwen, and Ernie (Yiyan).

What This Extension Does Not Do

  • It does not write account details, passwords, cookies, tokens, or session state to extension storage or a developer server.
  • It does not send conversation content or authentication credentials to the developer, advertisers, or analytics services.
  • It does not automatically bulk-fetch other conversations in your account; it processes only the conversation currently open.
  • It does not load remote code, serve ads, build user profiles, or perform behavioral analytics.

Changes to This Policy

If the extension's data handling changes, this page will be updated before the new version is released, and the change will be stated in the store release notes.
