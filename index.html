AI Chat Local Exporter — 隐私政策

最后更新：2026 年 8 月 1 日

一句话概括

本扩展没有服务器，没有账号系统，不会把您的任何数据发送给开发者或任何第三方。所有处理都在您自己的浏览器里完成，导出的文件直接保存到您自己的电脑。

在 DeepSeek 上导出时，本扩展会以您自己的登录身份向 DeepSeek 自己的服务器请求您自己的对话记录——这是本扩展唯一会发起的网络请求，详见下方「关于网络请求」。

我们收集什么数据

开发者不收集任何数据。

本扩展不会向开发者或任何第三方收集、传输、出售或共享以下任何一类信息：

  • 个人身份信息（姓名、地址、邮箱、身份证件等）
  • 健康信息
  • 财务和付款信息
  • 身份验证信息（密码、凭据、Cookie、Token、登录态）
    ※ 例外：在 DeepSeek 上导出时，扩展会读取该页面自身已有的登录凭据，并原样附加在发往 DeepSeek 自己服务器的请求头上。该凭据不会被存储，也不会发送给开发者或任何第三方。详见「关于网络请求」。
  • 个人通讯（您与 AI 的对话内容）
  • 位置信息
  • 网络记录（浏览历史、点击记录）
  • 用户活动（按键、鼠标操作、使用统计）
  • 网站内容

本扩展如何工作

  1. 您在受支持的 AI 平台页面上点击本扩展的图标。
  2. 本扩展读取该页面上已经显示出来的对话文本。
  3. 在您的浏览器内部把文本整理成 Markdown、Text、CSV 或 JSON。
  4. 通过浏览器的下载功能，把文件保存到您自己指定的本地位置。

整理和写文件的全过程都在您的浏览器内完成，不经过任何服务器。

关于网络请求

在本扩展支持的 10 个平台中，有 9 个完全不发起任何网络请求，扩展只读取页面上已经渲染出来的文本。

唯一的例外是 DeepSeek。

DeepSeek 的网页不会把长对话的完整历史渲染到页面上。因此在 DeepSeek 上导出时，本扩展会以您自己的登录身份，向 DeepSeek 自己的历史接口请求您自己的这一条对话记录。

  • 请求的发起方是您的浏览器，接收方是 DeepSeek 自己的服务器。
  • 数据不经过任何第三方，也不会发送到本扩展作者的任何服务器——本扩展没有服务器。
  • 为完成这个请求，扩展会读取 DeepSeek 页面自身已有的登录凭据，并原样附加在请求头上。该凭据不存储、不上传、不用于任何其他用途。
  • 请求内容仅限您当前正在查看的那一条对话，不会批量拉取您的其他会话。

换句话说：这条请求要到的数据，是 DeepSeek 本来就替您保存着的、属于您自己的内容。

  • 不会将数据用于与核心功能无关的任何用途。
  • 不会将数据用于确定信用度或放贷用途。

儿童隐私

开发者不收集任何数据，因此也不会收集儿童的数据。

政策变更

如果本扩展未来新增了任何涉及数据传输的功能，我们会在功能上线之前更新本页面，并在扩展的更新说明中明确告知。

AI Chat Local Exporter — Privacy Policy

Last updated: August 1, 2026

Summary

This extension has no server, no account system, and sends none of your data to the developer or any third party. All processing happens locally in your own browser, and exported files are saved directly to your own computer.

When exporting on DeepSeek, the extension requests your own conversation from DeepSeek's own server using your own logged-in session. That is the only network request this extension ever makes — see Network Requests below.

Data We Collect

The developer collects nothing. This extension does not collect, transmit, sell, or share any of the following with the developer or any third party: personally identifiable information, health information, financial and payment information, authentication information, personal communications, location, web history, user activity, or website content.

※ One exception regarding authentication information: on DeepSeek, the extension reads the credential already present in that page and attaches it, unchanged, to a request sent to DeepSeek's own server. That credential is never stored and never sent to the developer or any third party.

How It Works

  1. You click the extension icon on a supported AI chat page.
  2. The extension reads the conversation text already rendered on that page.
  3. It formats that text into Markdown, Text, CSV, or JSON entirely within your browser.
  4. It saves the file to a local location you choose, using the browser's download API.

Formatting and file writing happen entirely inside your browser, with no server involved.

Network Requests

Of the 10 supported platforms, 9 involve no network request at all — the extension only reads text already rendered on the page.

DeepSeek is the sole exception.

DeepSeek's web page does not render the full history of a long conversation. When exporting on DeepSeek, the extension therefore requests your own conversation from DeepSeek's own history endpoint, using your own logged-in session.

  • The request originates from your browser and is received by DeepSeek's own server.
  • No third party is involved, and nothing is sent to the developer's servers — this extension has no server.
  • To make that request, the extension reads the credential already present in the DeepSeek page and attaches it unchanged to the request header. It is never stored, never uploaded, and never used for anything else.
  • Only the conversation you are currently viewing is requested. Your other conversations are not fetched.

In short: this request retrieves data that DeepSeek already stores on your behalf, and that belongs to you.

What This Extension Never Does

  • Never stores your credentials, cookies, tokens, or session state on any platform, and never reads them except for the same-origin credential required for DeepSeek export.
  • Never uploads content to the developer's servers or any third-party server (there is no server).
  • Never calls any AI platform's internal API, other than DeepSeek's history endpoint.
  • Never bulk-scrapes your conversation history; only the conversation you currently have open is processed.
  • Never loads remote code.
  • Never serves ads, builds user profiles, or performs behavioral analytics.
  • Never uses any third-party analytics, telemetry, or crash-reporting service.

Data Sharing and Sale

Because the developer collects no data, no data is sold to third parties, used for any purpose unrelated to the extension's single purpose, or used for creditworthiness or lending purposes.

Changes to This Policy

If this extension ever adds a feature that transmits data, this page will be updated before that feature ships, and the change will be stated explicitly in the extension's release notes.
