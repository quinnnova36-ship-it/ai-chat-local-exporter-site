AI Chat Local Exporter — 隐私政策

最后更新：2026 年 7 月 31 日

一句话概括

本扩展不收集、不存储、不上传您的任何数据。所有处理都在您自己的浏览器里完成，导出的文件直接保存到您自己的电脑。本扩展没有服务器，也没有账号系统。

我们收集什么数据

不收集任何数据。

本扩展不会收集、传输、出售或共享以下任何一类信息：

  • 个人身份信息（姓名、地址、邮箱、身份证件等）
  • 健康信息
  • 财务和付款信息
  • 身份验证信息（密码、凭据、Cookie、Token、登录态）
  • 个人通讯（您与 AI 的对话内容）
  • 位置信息
  • 网络记录（浏览历史、点击记录）
  • 用户活动（按键、鼠标操作、使用统计）
  • 网站内容

本扩展如何工作

  1. 您在受支持的 AI 平台页面上点击本扩展的图标。
  2. 本扩展读取该页面上已经显示出来的对话文本。
  3. 在您的浏览器内部把文本整理成 Markdown、Text、CSV 或 JSON。
  4. 通过浏览器的下载功能，把文件保存到您自己指定的本地位置。

整个过程不涉及任何网络请求。对话内容从未离开您的设备。

权限说明

权限用途
activeTab 仅在您主动点击扩展图标时，访问当前这一个标签页，用于读取当前对话内容。不访问其他标签页。

本扩展不会做的事

  • 不读取、不保存您在任何平台的账号、密码、Cookie、Token 或登录态。
  • 不上传任何内容到任何服务器（本扩展没有服务器）。

数据共享与出售

因为本扩展不收集任何数据，所以：

  • 不会将数据出售给第三方。
  • 不会将数据用于与核心功能无关的任何用途。
  • 不会将数据用于确定信用度或放贷用途。

儿童隐私

本扩展不收集任何数据，因此也不会收集儿童的数据。

政策变更

如果本扩展未来新增了任何涉及数据传输的功能，我们会在功能上线之前更新本页面，并在扩展的更新说明中明确告知。

AI Chat Local Exporter — Privacy Policy

Last updated: July 31, 2026

Summary

This extension does not collect, store, or transmit any user data. All processing happens locally in your own browser, and exported files are saved directly to your own computer. This extension has no server and no account system.

Data We Collect

None. This extension does not collect, transmit, sell, or share any of the following: personally identifiable information, health information, financial and payment information, authentication information, personal communications, location, web history, user activity, or website content.

How It Works

  1. You click the extension icon on a supported AI chat page.
  2. The extension reads the conversation text already rendered on that page.
  3. It formats that text into Markdown, Text, CSV, or JSON entirely within your browser.
  4. It saves the file to a local location you choose, using the browser's download API.

No network request is made at any point. Your conversation content never leaves your device.

Permission Justifications

PermissionWhy it is needed
activeTab Accesses only the current tab, and only when you explicitly click the extension icon, in order to read the conversation shown on that page. No other tab is accessed.
downloads Writes the generated file to your local disk. Used solely to deliver the export result.
scripting Injects the extraction script into the current AI chat page to read the rendered conversation text. All scripts are bundled with the extension; no remote code is ever loaded.
Host permissions Strictly limited to the supported AI platform domains listed below. The extension does not run on any other website.

Supported Sites

ChatGPT, Google Gemini, Claude, Grok, DeepSeek, Doubao, Kimi, Tencent Yuanbao, Tongyi Qianwen, and Ernie (Yiyan).

What This Extension Never Does

  • Never reads or stores your credentials, cookies, tokens, or session state on any platform.
  • Never uploads content to any server (there is no server).
  • Never calls the AI platforms' internal APIs.
  • Never bulk-scrapes your conversation history automatically.
  • Never loads remote code.
  • Never serves ads, builds user profiles, or performs behavioral analytics.
  • Never uses any third-party analytics, telemetry, or crash-reporting service.

Data Sharing and Sale

Because no data is collected, no data is sold to third parties, used for any purpose unrelated to the extension's single purpose, or used for creditworthiness or lending purposes.

Changes to This Policy

If this extension ever adds a feature that transmits data, this page will be updated before that feature ships, and the change will be stated explicitly in the extension's release notes.
